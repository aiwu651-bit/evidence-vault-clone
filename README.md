# 工程证据管理站点复刻版

这是一个独立的本地前端复刻版本，参考了 `https://evidence.cybertumu.com/` 的信息架构和视觉风格，但没有拷贝对方构建产物或图片资源。

运行方式：

```bash
node server.mjs
```

打开：

```text
http://localhost:4177/
```

页面包含首页、证据仓库、项目详情、项目列表、待处理中心、结算报告、系统设置和 AI 助手浮层。

已实现的本地功能：

- 新建项目、加载演示项目
- 新增单条存证、批量导入存证
- 保存施工日志
- 存证筛选、搜索、状态变更、删除
- 待处理队列自动计算
- 结算报告预览，并导出 Markdown 或 CSV
- 工作区设置保存
- AI 助手按当前本地数据生成修复建议

数据保存在浏览器本地存储里，刷新页面后仍会保留。需要清空时进入“系统设置”点击“清空本地工作区”。
